## Contact Form Email

Set these environment variables in your deployment:

- `NEXT_PUBLIC_SITE_URL` (e.g. `https://www.dittdomene.no`)
- `NEXT_PUBLIC_ORG_SAME_AS` (optional comma-separated profile URLs)
- `NEXT_PUBLIC_FOUNDING_DATE` (optional `YYYY-MM-DD`)
- `NEXT_PUBLIC_AUTHOR_SAME_AS` (optional comma-separated author profile URLs)
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASS`
- `SMTP_SECURE` (optional, defaults to `true` when port is 465)
- `CONTACT_TO`
- `CONTACT_FROM` (optional, defaults to `SMTP_USER`)
