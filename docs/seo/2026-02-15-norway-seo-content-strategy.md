# ZWEB SEO- og Innholdsstrategi (Norge, Bokmål) – 15.02.2026

## 1) Antakelser og ukjente forhold
- Nettstedet er et SMB-fokusert webbyrå i Norge med primært mål om leads via organisk søk.
- Vi har ikke tilgang til Google Search Console, GA4, Ahrefs/Semrush eller faktiske konverteringsdata i denne leveransen.
- Søkevolum og vanskelighetsgrad er derfor estimert via intensjon, SERP-observasjoner og kommersiell relevans (ikke eksakte volumtall).
- SERP-er varierer per sted/enhet/personalisering. Anbefalingene er laget for norsk marked generelt, med prioritet på norske bedriftseiere.

## 2) Norge-first SERP-funn (oppsummering)
### Observerte mønstre
- Kjøpsnære søk domineres av tjenestesider med tydelig verdiforslag + CTA, ofte med "pris"/"fra" i overskrift.
- Informasjonssøk domineres av guider/sammenligninger: pris, plattformvalg (WordPress/Webflow/Shopify), og valg av byrå.
- Lokal intensjon går igjen i søk etter byrå (by/region + fagområde) og i sider som fremhever norsk markedskompetanse.
- E-handelssøk viser sterk kommersiell intensjon rundt plattform, migrering og veksttjenester.

### Konsekvens for zweb.no
- Trenger tydeligere topic clusters rundt `pris`, `plattformvalg`, `SEO`, `drift/vedlikehold`, `nettbutikk`.
- Trenger sterkere internlenking fra informasjonsartikler til kommersielle sider.
- Bør bruke mer eksplisitt norsk kjøpsspråk ("hva koster", "hvilket byrå", "hva er inkludert", "for små bedrifter i Norge").

## 5) On-page anbefalinger (zweb.no)

### Side-mal: Kommersielle tjenestesider
- H1 med tydelig søkeintensjon + målgruppe (`Nettside for bedrift i Norge` osv.).
- Over fold: verdiforslag + sosial bevisføring + primær CTA.
- Egne seksjoner for `pris`, `hva er inkludert`, `prosess`, `hvor lang tid`, `hvem passer tjenesten for`.
- FAQ (minst 4–6 spørsmål) i klart kjøpsspråk.
- Internlenker til relevante guider + case.

### Side-mal: Bloggartikler (informasjon + kommersiell bro)
- Problemorientert ingress som matcher søkeintensjon.
- Innholdsfortegnelse, tydelige mellomtitler, konkrete eksempler.
- Seksjon for vanlige feil + handlingsplan.
- FAQ nederst med spørsmål bedriftseiere faktisk stiller.
- 3–5 interne lenker til relevante money pages.

### CTR-forbedringer
- Tittelmal: `Primært søkeord + norsk kontekst + konkret nytte`.
- Meta description: tydelig outcome + sekundært søkeord + CTA.
- Unngå overlappende title/description mellom artikler med lik intensjon.

## 6) Teknisk SEO-sjekkliste (Next.js/Vercel)

### Må være på plass
- Stabil canonical-domain (`https://zweb.no`) i metadataBase/canonical.
- Korrekte metadata per sidetype (`website`, `article`, OpenGraph, Twitter).
- Oppdatert `robots.txt` med sitemap-lenke.
- Generert `sitemap.xml` med alle viktige ruter + oppdatert lastModified.
- JSON-LD for Organization/LocalBusiness/WebSite/Service/Article/FAQ/Breadcrumb.
- Konsistent internlenking mellom informative og kommersielle sider.
- Mobil ytelse og Core Web Vitals (LCP/CLS/INP) følges opp.

### Bør inn i neste sprint
- Egen XML-sitemap for blogg hvis antall artikler øker raskt.
- Måling av konverteringshendelser per sidetype (skjema, telefon, CTA-klikk).
- Innholdsoppdateringsrutine hver 60–90 dag for artikler med trafikk.
- E-E-A-T-signaler: tydelig forfatterprofil, oppdatert dato, kilder.

## 7) Internlenkeplan (cluster -> money pages)

### Prinsipper
- Hver bloggpost skal ha minst 3 interne lenker til kommersielle sider.
- Minst én lenke tidlig i artikkelen (etter intro/problem), én i midten, én nær CTA.
- Ankertekst skal beskrive verdi, ikke bare "les mer".

### Link-map
- Pris/økonomi-artikler -> `/priser`, `/kontakt`, `/drift-og-vedlikehold`
- Byråvalg-artikler -> `/webdesign-byra`, `/case`, `/kontakt`
- WordPress/Webflow-artikler -> `/wordpress-nettside`, `/webflow-nettside`, `/kontakt`
- Nettbutikk-artikler -> `/nettbutikk`, `/priser`, `/kontakt`
- SEO-artikler -> `/seo-for-nettsider`, `/kontakt`, relevante bransjesider
- Bransjeartikler -> `/bransjer/handverker` eller `/bransjer/advokat`, `/kontakt`

## 8) Publiseringsplan (6–8 uker)
- Uke 1–2: publiser 3 kjøpsnære artikler (pris/byrå/plattform).
- Uke 3–4: publiser 2 SEO/drift-artikler + oppdater topperformere.
- Uke 5–6: publiser 2 nettbutikk-/migreringsartikler.
- Uke 7–8: oppdater metatitler/meta descriptions basert på tidlig CTR-signaler.
